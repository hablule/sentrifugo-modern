# Security Policy

## Supported Versions
Only **Sentrifugo Modern (PHP 8.3+)** is actively maintained for security patches.

| Version | Supported |
| :--- | :--- |
| Sentrifugo Modern (main) | :white_check_mark: |
| Legacy Sentrifugo (< 3.2) | :x: |

## Reporting a Vulnerability

We take the security of organizational HR, payroll, and employee records seriously.

If you discover a security vulnerability within Sentrifugo Modern:
1. **Do NOT open a public GitHub Issue.**
2. Please report vulnerabilities privately by emailing the maintainer directly or using [GitHub Private Vulnerability Reporting](https://github.com/hablule/sentrifugo-modern/security/advisories/new).
3. Include detailed steps to reproduce the vulnerability, a proof of concept (PoC), and the impacted module.

We will acknowledge receipt within 48 hours and work with you to release a patch promptly.
